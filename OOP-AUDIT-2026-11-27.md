# OOP compatibility audit (2026-11-27)

Reference: bundled Cambridge International AS & A Level Computer Science 9618 Pseudocode Guide for Teachers for 2026, section 10 (Methods and Properties; Constructors and Inheritance).

Implemented fixes:
- Unqualified function calls inside an object method resolve to methods on the current instance, including private methods. They no longer fall through to unsupported built-in function handling.
- Unqualified CALL statements inside object methods resolve to procedures on the current instance.
- TODAY(), DAY(), MONTH(), YEAR() support DATE arithmetic used by the submitted CalculateAge example. These are runner conveniences; do not treat them as established Cambridge 9618 built-ins based on section 10.
- Errors from a nested method are propagated rather than silently replaced with a misleading missing-RETURN error.
- The live semantic function whitelist recognizes the DATE conveniences.

Tested: method calls before declarations, constructor, inherited constructor via SUPER.NEW, inherited methods, public/private access, private method calls from within the class, object composition and chained getters, missing RETURN, unknown method, DATE calculations, original Load/Route/Crew example.

Limitations: These tests do not constitute exhaustive language conformance. Further tests are required for every permitted nesting and polymorphism scenario, property shadowing, inherited access rules, and full browser behavior. The source remains a single-file interpreter rather than a typed-AST implementation.
