
# Pseudocode Runner

Pseudocode Runner is a free, browser-based pseudocode editor and interpreter developed for students at Acacia College, targetted at students stuyfing UTC2852. It provides an interactive environment for writing, executing, and debugging pseudocode to support computational thinking and programming fundamentals.

The platform is based on Cambridge International AS & A Level Computer Science (9618) pseudocode conventions, with additional functionality for classroom learning and experimentation.

## Key Features

1. **Pseudocode Execution:** Write and execute pseudocode involving variables, constants, arrays, conditional statements, loops, procedures, functions, recursion, and object-oriented programming.
2. **Interactive Input and Output:** Enter values during program execution and view results in a dedicated output panel.
3. **Live Error Detection:** Identify syntax and selected semantic errors with line-specific diagnostic messages.
4. **Variable Inspection:** Monitor variable values and program states during execution.
5. **File Management:** Import and export pseudocode as `.txt` files for classroom activities and independent practice.
6. **Browser-Based Access:** Run pseudocode directly in the browser without installation, student accounts, or login.

## Educational Purpose

The runner is designed to support the teaching and learning of computational thinking, with an emphasis on algorithmic reasoning, problem-solving, and debugging.

Students can independently experiment with pseudocode, observe program behavior, identify errors, and refine their solutions without requiring knowledge of a conventional programming language.

The platform is intended for educational use and is not an official Cambridge examination product.
